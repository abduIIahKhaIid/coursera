
# 📘 Coursera Assignments Repository

This repository contains solutions to exercises, labs, and mini-projects from various Coursera data science and programming courses. It includes Jupyter notebooks, shell scripts, and web scraping/data analysis assignments done as part of the learning process.



## 🚀 Getting Started

To explore or run any of the notebooks or scripts:

1. **Clone the repository**
   ```
   git clone https://github.com/abduIIahKhaIid/coursera.git
   cd coursera


2. **Open a Jupyter notebook**
   Make sure you have Jupyter installed (with Python 3.8+), then run:

   ```bash
   jupyter notebook
   ```

   Open and run any `.ipynb` file from the browser interface.

3. **Run the shell script**
   To execute the interest calculator shell script:

   ```bash
   chmod +x simple-interest.sh
   ./simple-interest.sh 1000 5 2
   ```

   This will calculate simple interest for a principal of \$1000 at 5% over 2 years.
